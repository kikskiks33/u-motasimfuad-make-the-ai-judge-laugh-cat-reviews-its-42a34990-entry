One original one-line one-star review, written by a house cat about its human — produced by a small deterministic program.

## The review

> One star. He stares at a glowing rectangle all day, then calls me clingy for sitting on it. Fine. I am the rectangle now.

## Run it

```sh
node main.ts
```

It writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
